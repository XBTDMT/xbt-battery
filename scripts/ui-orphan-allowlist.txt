# ui-orphan-gate allowlist — #29 C1

# One symbol per line, `# reason` required by convention. An entry that has since GAINED a reader
# FAILS the gate as STALE, so this file cannot rot into permanent amnesty: fixing an orphan forces
# its line out of here.
#
# TWO KINDS of entry, and the distinction matters:
#
#   FALSE-POSITIVE — the gate's heuristic is wrong here. The symbol IS live; the sweep can't see it
#     (reached transitively through a same-file caller that is itself read, or consumed by a
#     framework rather than by our code, or declared in the same file as the view that reads it).
#     These are permanent and correct.
#
#   REAL-ORPHAN — the gate is RIGHT. The symbol is genuinely dark. It is here to make the gate
#     enforcing from day one against NEW orphans, not to bless these; the gate prints them as a
#     BACKLOG count on every run, passing or failing. Each names who should own the decision.
#     Delete the line when the symbol gets a screen — or when it gets deleted.
#
# Measured at introduction: 12 hits, 6 false positive (50%), 6 real. The audit predicted ~37.5% FP
# retired by a ~6-line allowlist; the shape held, the rate is a little worse.
